Vokabeln · Question 1

彼かれは小説家しょうせつか（　　）有名ゆうめいになったが、普段ふだんは小ちいさい病院びょういんで働はたらく医者いしゃだ。

  1. について
  2. として
  3. にしたがって
  4. と比くらべて
Correct answer + explanation: として = 'as / in the role of': 小説家として有名になった = 'became famous as a novelist'. ❌ について = 'about (a topic)'. ❌ にしたがって = 'in accordance with'. ❌ と比べて = 'compared to'. 💡 として = identity/role under which something happens.

Vokabeln · Question 2

先週せんしゅう、会社かいしゃの面接めんせつで「もし自分じぶんを色いろで表あらわす（　　）、何色なにいろですか。」と聞きかれ、オレンジ色いろと答こたえた。「元気げんき」や「健康けんこ」のイメージがあるからだ。

  1. ことから
  2. という点てんで
  3. ように
  4. としたら
Correct answer + explanation: としたら = 'if (we) suppose': もし自分を色で表すとしたら = 'if you were to express yourself in color'. ❌ ことから = 'from the fact that'. ❌ という点で = 'in terms of'. ❌ ように = 'like/so that'. 💡 としたら = hypothetical conditional (if we suppose).

Vokabeln · Question 3

昨日きのうの夜よる、寝ねる前まえに（　　）ヨーグルトが食たべたくなって、夜中よなかなのにコンビニに買かいに行いってしまった。

  1. どうか
  2. せっかく
  3. どうしても
  4. きっと
Correct answer + explanation: どうしても + wish = 'really want to / can't help but': どうしても食べたくなって = 'came to really want to eat'. ❌ どうか = 'please (begging)'. ❌ せっかく = 'with effort / taking the trouble'. ❌ きっと = 'surely'. 💡 どうしても〜たい = irresistible desire.

Vokabeln · Question 4

このケーキは材料ざいりょうを混まぜて焼やく（　　）から、誰だれでも失敗しっぱいせずに美味おいしく作つくれる。

  1. だけだ
  2. ことだ
  3. せいだ
  4. ときだ
Correct answer + explanation: 〜だけだ = 'just / only': 混ぜて焼くだけだから = 'because it's just a matter of mixing and baking' — this is why anyone can succeed. ❌ ことだ = 'the thing is / you should' — sentence-final advice; it does not combine with から to give a cause here. ❌ せいだ = 'because of (blame)' — negative. ❌ ときだ = 'it is the time'. 💡 〜だけだから = 'since it's simply 〜' (cause + ease).

Verb conjugation · Question 5

私わたしの町まちでは毎年まいとし8月がつ最後さいごの日曜日にちようびに夏祭なつまつりが（　　）。

  1. 行おこないます
  2. 行おこなわせます
  3. 行おこなっています
  4. 行おこなわれます
Correct answer + explanation: 行われます = passive: 夏祭りが行われます = 'the festival is held'. The festival doesn't perform the act. ❌ 行います = active (we hold it) — subject would need to be the organizers. ❌ 行わせます = causative ('make hold'). ❌ 行っています = 'is holding (ongoing)'. 💡 Passive for events organized by others.

Politeness & expressions · Question 6

（靴屋くつやで）
客きゃく「すみません。この靴くつのもう一ひとつ大おおきいサイズはありますか。」
店員てんいん「あ、はい、確認かくにんしますので、少々（　　）。」

  1. お待まちしております
  2. お待まちください
  3. お待まちできます
  4. お待まちしましょう
Correct answer + explanation: お待ちください = 'please wait (a moment)' — the standard polite request a clerk makes before checking on something: 少々お待ちください = 'please wait a moment.' ❌ お待ちしております = 'I am waiting (for you)' — a set phrase (we look forward to serving you), not used when asking a customer to wait. ❌ お待ちできます = 'I can wait' — the clerk is not the one waiting. ❌ お待ちしましょう = 'let’s wait' — includes the speaker, inappropriate here. 💡 少々お待ちください = fixed service phrase.

Politeness & expressions · Question 7

（電話でんわで）
Ｘ建設けんせつの社員しゃいん「はい、Ｘ建設けんせつ営業えいぎょう部ぶです。」
中田なかた「あ、私わたし、ABC銀行ぎんこうの中田なかたと（　　）が、山石やまいしさんをお願ねがいします。」

  1. ございます
  2. いたします
  3. 申もうします
  4. 申もうし上あげます
Correct answer + explanation: 申します = 'I am called 〜' (humble): 中田と申します = 'I am Nakada'. ❌ ございます = 'to exist (polite)'. ❌ いたします = polite する — but the pattern is [name]と申します. ❌ 申し上げます = humble 'say' used for messages, not self-introduction. 💡 〜と申します = my name is.

Vokabeln · Question 9

昼寝ひるねをするのは気持きもちがいいが、夜よる（　　）困こまるので、いつも15分ふんぐらいで起おきる。

  1. 寝ねなくて
  2. 寝ねられると思おもって
  3. 寝ねられないと
  4. 寝ねると思おもうと
Correct answer + explanation: 寝られないと困る = 'if I can't sleep (well), it's a problem'. と introduces the condition that causes 困る. ❌ 寝なくて = 'not sleeping' — then the subject would shift. ❌ 寝られると思って = 'thinking I'll be able to sleep'. ❌ 寝ると思うと = 'thinking that I'll sleep'. 💡 〜ないと困る = if not 〜, trouble.

Adjektive · Question 10

Ａ市しは、保育園ほいくえんの数かずが少なく、保育園ほいくえんを（　　）利用りようできない人ひとがいることが問題もんだいになっている。

  1. 利用りようしたくても
  2. 利用りようしそうになって
  3. 利用りようしているのに
  4. 利用りようできたら
Correct answer + explanation: 〜たくても = 'even if (one) wants to': 利用したくても利用できない = 'even if they want to use it, they can't'. ❌ しそうになって = 'about to'. ❌ しているのに = 'although using'. ❌ できたら = 'if they could'. 💡 たい-form + も = desire thwarted by reality.

Verb conjugation · Question 11

Sentence structure · Question 18
