Alle 50 Fragen (mit Antworten & Erklärungen)

Vokabeln · Question 1

昨日きのうの宿題しゅくだいは少すくなかったので、（　　）終おわりました。

  1. 20分ふん
  2. 20分ふんしか
  3. 20分ふんで
  4. 20分ふんを
Richtige Antwort + Erklärung: 20分で = 'in 20 Minuten' (Zeit zum Fertigstellen). ❌ 20分 ohne Partikel ungrammatisch. ❌ 20分しか = 'nur 20 Minuten' — würde zu wenig Zeit bedeuten. ❌ 20分を — を passt nicht. 💡 Zeitspanne zum Abschluss = で.

Partikel · Question 2

このロボットは人ひと（　　）会話かいわすることができます。

  1. や
  2. を
  3. へ
  4. と
Richtige Antwort + Erklärung: と markiert den Gesprächspartner: 人と会話する = 'mit Menschen sprechen'. ❌ ゛や zählt auf. ❌ を = Objekt, aber 会話 ist intransitiv. ❌ へ = Richtung. 💡 会話する/話す nehmen と für den Partner.

Partikel · Question 3

弟おとうとは小ちいさいときよく怪我けがをして、両親りょうしん（　　）心配しんぱいさせました。

  1. で
  2. を
  3. の
  4. や
Richtige Antwort + Erklärung: Kausativ: 両親を心配させました = 'ließ meine Eltern sich sorgen'. を markiert die Person. ❌ で = Mittel/Ort. ❌ の = Besitz. ❌ や = Aufzählung. 💡 Emotions-Kausative (心配させる、驚かせる) nehmen を.

Partikel · Question 4

ホテルの朝あさご飯はんのパンがとても美味おいしかったので、八やっつ（　　）食たべました。

  1. も
  2. に
  3. が
  4. で
Richtige Antwort + Erklärung: も nach Zählwort = 'sogar': 八つも = 'gleich acht Stück!'. ❌ に = Zeit. ❌ が = Subjekt. ❌ で = Gesamtpreis. 💡 Menge + も drückt Überraschung aus.

Partikel · Question 5

この日本にほん語ごの辞書じしょは、30年ねん前まえに外国人がいこくじん（　　）作つくられました。

  1. から
  2. を
  3. について
  4. によって
Richtige Antwort + Erklärung: によって = 'von (durch)' im Passiv: 外国人によって作られました. ❌ から = Quelle. ❌ を = Objekt. ❌ について = 'über'. 💡 Passiv-Ausführer = によって oder に.

Vokabeln · Question 6

Ａ市しの運動うんどう場ばは（　　）使つかえますが、予約よやくが必要ひつようです。

  1. だれでも
  2. だれを
  3. だれに
  4. だれが
Richtige Antwort + Erklärung: だれでも = 'jeder': jeder darf es nutzen. ❌ だれを falsch in 〜でも-Muster. ❌ だれに = 'wem'. ❌ だれが = Frage. 💡 疑問詞 + でも = 'beliebig-': だれでも、どこでも、いつでも.

Vokabeln · Question 7

「リーさん、いつも（　　）国くにの家族かぞくに連絡れんらくしますか。」
「メールを書かくことが多おおいです。」

  1. どのぐらい
  2. どの
  3. どうやって
  4. どういう
Richtige Antwort + Erklärung: どうやって = 'wie (mit welcher Methode)'. Die Antwort 'E-Mails' ist eine Methode. ❌ どのぐらい = 'wie viel'. ❌ どの = 'welches (+Nomen)'. ❌ どういう = 'was für ein'. 💡 Methodenfragen: どうやって.

Vokabeln · Question 8

娘むすめは先月せんげつ高校こうこうを卒業そつぎょうしました。（　　）大学だいがくの入学にゅうがく式しきです。

  1. だんだん
  2. あまり
  3. だいたい
  4. もうすぐ

Vokabeln · Question 9

今朝けさは駅えきに行いくバスが（　　）来きなかったので、タクシーで行いきました。

  1. やっと
  2. なかなか
  3. きっと
  4. いつか
Richtige Antwort + Erklärung: なかなか + verneint = 'gar nicht/bloß nicht': なかなか来なかった = 'kam lange nicht'. ❌ やっと = 'endlich'. ❌ きっと = 'bestimmt'. ❌ いつか = 'irgendwann'. 💡 なかなか〜ない = feststehende Struktur.

Vokabeln · Question 10

「あしたかあさって、カラオケに行いかない」
「あ、いいね。あしたは都合つごうが悪わるいけど、あさって（　　）だいじょうぶだよ。」

  1. なのに
  2. だから
  3. でも
  4. なら
Richtige Antwort + Erklärung: なら = 'wenn (es) der Fall ist': あさってなら = 'wenn übermorgen, dann OK'. ❌ なのに = 'obwohl'. ❌ だから = 'deshalb'. ❌ でも = 'aber'. 💡 なら reagiert auf einen Vorschlag.

Partikel · Question 11

私わたしは夏休なつやすみ（　　）間あいだ、スーパーでアルバイトをしていました。

  1. に
  2. で
  3. の
  4. —
Richtige Antwort + Erklärung: 夏休みの間 = 'während der Sommerferien' — の verbindet mit 間. ❌ に = Zeitpunkt, nicht Dauer. ❌ で falsch mit 間. 💡 〜の間（あいだ） = während.

Vokabeln · Question 12

先週せんしゅう庭にわの木きの枝えだを切きりました。ぜんぶ（　　）2時間じかん掛かかりました。

  1. 切きったり
  2. 切きるのに
  3. 切きりに
  4. 切きるかどうか
Richtige Antwort + Erklärung: 切るのに = 'zum Schneiden (brauchte Zeit)' — のに verbindet mit かかる. ❌ 切ったり = 'schneiden und so'. ❌ 切りに — falsche Form. ❌ 切るかどうか = 'ob man schneidet'. 💡 Verb + のに = 'dafür brauchte…'.

Vokabeln · Question 13

「あしたの午後ごご、サッカーの練習れんしゅうに行いきますか。」
「ええ、行いきます。でも、午前ごぜん中ちゅうに用事ようじがあるので、（　　）。」

  1. 遅おくれないでください
  2. 遅おくれないほうがいいです
  3. 遅おくれるかもしれません
  4. 遅おくれてはいけません
Richtige Antwort + Erklärung: 遅れるかもしれません = 'vielleicht komme ich zu spät' (hat Verpflichtung). ❌ 遅れないでください = Bitte — falsche Rolle. ❌ 遅れないほうがいいです = 'wäre besser nicht zu spät'. ❌ 遅れてはいけません = 'darf nicht zu spät'. 💡 かもしれません = vielleicht.

Vokabeln · Question 14

（食堂しょくどうで）
「空あいている席せきがありませんね。」
「ええ。あ、でも、あそこの席せきが（　　）よ。」
「本当ですね。空あくまで、少し待まちましょう。」

  1. 空あきそうです
  2. 空あきました
  3. 空あいています
  4. 空あいたようです
Richtige Antwort + Erklärung: 空きそうです = 'sieht so aus, als würde es frei' (そうです = Vermutung). ❌ 空きました = schon frei — widerspricht dem Warten. ❌ 空いています = frei — Widerspruch. ❌ 空いたようです = scheint frei. 💡 Stamm + そう = sieht so aus.

Vokabeln · Question 15

（会議かいぎ室しつで）
「会議かいぎの準備じゅんびは終おわりましたか。手伝てつだいましょうか。」
「ありがとうございます。じゃあ、いすが一ひとつ足たりないので、隣となりの会議かいぎ室しつから（　　）。」
「はい、わかりました。」

  1. 持もってこなくてもいいですか
  2. 持もってきてもらえますか
  3. 持もってこないといけませんか
  4. 持もってきていませんか
Richtige Antwort + Erklärung: 持ってきてもらえますか = 'könntest du einen bringen?'. Die Person bietet Hilfe an → Bitte passt. ❌ 〜なくてもいいですか = 'darf ich nicht bringen?'. ❌ 〜ないといけませんか = umgekehrte Rolle. 💡 〜てもらえますか = höfliche Bitte.

Sentence structure · Question 16

雨あめが（　　）、試合しあいは中止ちゅうしになりました。

  1. 降ふったので
  2. 降ふりながら
  3. 降ふっても
  4. 降ふると
Richtige Antwort + Erklärung: 降ったので = 'weil es regnete': 雨が降ったので、試合は中止になりました. ❌ 降りながら = 'während es regnet'. ❌ 降っても = 'selbst wenn'. ❌ 降ると = 'immer wenn'. 💡 Vergangenheit + ので = weil (Ursache).

Sentence structure · Question 17

昨日きのうの夜よる家いえに帰かえってから、鍵かぎを（　　）覚おぼえていません。

  1. どこに置おいたか
  2. どこに置おく
  3. どこに置おいて
  4. どこに置おいたら
Richtige Antwort + Erklärung: どこに置いたか覚えていません = 'ich erinnere mich nicht, wo ich den Schlüssel hingelegt habe.' Eingebettete Frage: Fragewort + Vergangenheit + か. ❌ 置く = Nicht-Vergangenheit. ❌ 置いて = te-Form. ❌ 置いたら = Konditional. 💡 Eingebettete W-Frage + か.

Sentence structure · Question 18

私わたしはピアノを（　　）時間じかんがありません。

  1. 引ひくのが
  2. 引ひく
  3. 最近さいきんす
  4. 好すきですが
Richtige Antwort + Erklärung: Satzbau: ピアノをひく時間がありません = 'keine Zeit, Klavier zu spielen'. ★ = ひく (Grundform vor 時間). ❌ ひくのが = nomalisiert. ❌ 最近す unvollständig. ❌ 好きですが kein Bezug. 💡 Grundform + 時間 = 'Zeit zum 〜'.

Sentence structure · Question 19

祖父そふが大切たいせつに（　　）時計とけいを、私わたしは今いまも使つかっています。

  1. 使つかっていた
  2. 使つかって
  3. 使つかう
  4. 使つかったら
Richtige Antwort + Erklärung: 使っていた = 'benutzte früher': 祖父が大切に使っていた時計 = 'die Uhr, die Großvater in Ehren benutzte.' ❌ 使って = te-Form modifiziert kein Nomen. ❌ 使う = Nicht-Vergangenheit. ❌ 使ったら = Konditional. 💡 〜ていた + Nomen = vergangener Zustand zum Nomen.

Sentence structure · Question 20

「来週らいしゅう、野球やきゅうの試合しあいを見みに行いこうと思おもっているんですが、いっしょにどうですか。」

  1. ぜひ行いきたい
  2. ことがない
  3. 見みに行いった
  4. ので
Richtige Antwort + Erklärung: Satzbau: ぜひ行きたいです = 'ich will unbedingt hingehen'. ❌ ことがない — unvollständig. ❌ 見に行った = Vergangenheit, Event ist nächste Woche. ❌ ので braucht einen Grund. 💡 ぜひ + Wunschform = begeisterter Wunsch.

  3. しりません
  4. さわりません
Richtige Antwort + Erklärung: 見つかりません = 'nicht gefunden' — intransitiv. ❌ つかまえません = kann nicht fangen (Lebewesen). ❌ しりません = weiß nicht (aber du suchst). ❌ さわりません = nicht berühren. 💡 Suchen + noch nicht gefunden = 見つかりません.

Vokabeln · Question 43

おとうとはあのきっさてんでアルバイトをしています。

  1. おとうとはあのきっさてんでまっています。
  2. おとうとはあのきっさてんで働はたらいています。
  3. おとうとはあのきっさてんでコーヒーを飲のんでいます。
  4. おとうとはあのきっさてんでともだちと話はなしています。
Richtige Antwort + Erklärung: アルバイトする = はたらく (arbeiten). Gleiche Bedeutung: はたらいています. ❌ まっています = wartet. ❌ 飲んでいます = trinkt. ❌ 話しています = spricht. 💡 アルバイト = arbeiten.

Vokabeln · Question 44

わたしは水泳すいえいがすきです。

  1. わたしは走はしるのがすきです。
  2. わたしは泳およぐのがすきです。
  3. わたしはごはんを食たべるのがすきです。
  4. わたしはほんを読よむのがすきです。

Vokabeln · Question 45

それを聞きいてびっくりしました。

  1. それを聞きいてわらいました。
  2. それを聞きいてこまりました。
  3. それを聞きいておこりました。
  4. それを聞きいて驚おどろきました。

Adjektive · Question 46

Verb conjugation · Question 47

さいきん毎朝まいあさジョギングを（　　）ようになりました。

  1. する
  2. して
  3. した
  4. できる
Richtige Antwort + Erklärung: 〜ようになる = 'hat sich angewöhnt': nimmt Grundform → する. ❌ して = te-Form. ❌ した = Vergangenheit. ❌ できる = 'können' — Bedeutung ändert sich. 💡 ようになる = allmählicher Wandel.

Vokabeln · Question 48

日本語にほんごの先生せんせいになる（　　）、大学だいがくに入はいりました。

  1. からに
  2. ように
  3. ことに
  4. ためために
Richtige Antwort + Erklärung: 〜ために = 'um zu': 先生になるために大学に入りました. ❌ からに — falsche Form. ❌ ように = 'damit' — für Wünsche, nicht feste Ziele. ❌ ことに — falsches Muster. 💡 Zweck: Grundform + ために.

Partikel · Question 49

事故じこがあった（　　）、道みちがこんでいます。

  1. を
  2. そうに
  3. からに
  4. ためために
Richtige Antwort + Erklärung: 〜ために = 'wegen': 事故があったために = 'wegen des Unfalls'. ❌ を — Objektmarker. ❌ そうに — falsche Form. ❌ からに — falsche Form. 💡 ために = Zweck UND Ursache.

Partikel · Question 50

その仕事しごと、私わたし（　　）させてください。

  1. に
  2. を
  3. で
  4. が
Richtige Antwort + Erklärung: Kausativ: 私にさせてください = 'bitte lassen Sie MICH es tun'. に markiert die erlaubte Person. ❌ を — für Objekte, nicht Personen. ❌ で = Mittel. ❌ が — grammatisch denkbar, aber Kausativ-Permission nutzt に. 💡 Kausativ-Bitte: [Person]に させてください.
