Vokabeln · Question 1

昨日きのうの宿題しゅくだいは少すくなかったので、（　　）終おわりました。

  1. 20分ふん
  2. 20分ふんしか
  3. 20分ふんで
  4. 20分ふんを
Correct answer + explanation: 20分で = 'in 20 minutes' (time needed to finish). ❌ 20分 plain = just a noun, no particle. ❌ 20分しか = 'only 20 minutes' — implies it was too little, but the homework was little so finishing fast is expected. ❌ 20分を — を doesn't attach to durations. 💡 Duration of completion = で.

Partikel · Question 2

このロボットは人ひと（　　）会話かいわすることができます。

  1. や
  2. を
  3. へ
  4. と
Correct answer + explanation: と marks a conversation partner: 人と会話する = 'converse with people'. ❌ や lists nouns ('A and B among others'). ❌ を = object, but 会話する doesn't act on the person. ❌ へ = direction. 💡 会話する/話す take と for the partner.

Partikel · Question 3

弟おとうとは小ちいさいときよく怪我けがをして、両親りょうしん（　　）心配しんぱいさせました。

  1. で
  2. を
  3. の
  4. や
Correct answer + explanation: Causative: 両親を心配させました = 'made (my) parents worry'. を marks the person made to feel the emotion. ❌ で = means/place. ❌ の = possessive. ❌ や = list marker. 💡 Causative of emotion (心配させる、驚かせる): person + を.

Partikel · Question 4

ホテルの朝あさご飯はんのパンがとても美味おいしかったので、八やっつ（　　）食たべました。

  1. も
  2. に
  3. が
  4. で
Correct answer + explanation: も after a counter = 'as many as': 八つも食べました = 'ate as many as eight!'. ❌ に = time/rate marker. ❌ が = subject. ❌ で = total price (五つで). 💡 Quantity + も expresses surprise at the amount.

Partikel · Question 5

この日本にほん語ごの辞書じしょは、30年ねん前まえに外国人がいこくじん（　　）作つくられました。

  1. から
  2. を
  3. について
  4. によって
Correct answer + explanation: によって = 'by (means of)' in passive sentences: 外国人によって作られました = 'made by a foreigner'. ❌ から = source (from). ❌ を = object. ❌ について = 'about (a topic)'. 💡 Passive agent = によって (formal) or に.

  1. に
  2. で
  3. の
  4. —

  2. 切きるのに
  3. 切きりに
  4. 切きるかどうか
Correct answer + explanation: 切るのに = 'for cutting (them all)' — のに = nominalized purpose of かかる. ❌ 切ったり = 'doing things like cutting' (たり-list). ❌ 切りに — wrong form. ❌ 切るかどうか = 'whether or not to cut'. 💡 Verb + のに = 'for doing 〜 (took time/money)'.

Vokabeln · Question 14

（食堂しょくどうで）

  2. 空あきました

Vokabeln · Question 15

（会議かいぎ室しつで）
「会議かいぎの準備じゅんびは終おわりましたか。手伝てつだいましょうか。」
「ありがとうございます。じゃあ、いすが一ひとつ足たりないので、隣となりの会議かいぎ室しつから（　　）。」

Sentence structure · Question 16

雨あめが（　　）、試合しあいは中止ちゅうしになりました。

  1. 降ふったので
  2. 降ふりながら
  3. 降ふっても
  4. 降ふると
Correct answer + explanation: 降ったので = 'because it rained': 雨が降ったので、試合は中止になりました = 'Because it rained, the game was cancelled.' Cause (ので) leads to the result. ❌ 降りながら = 'while raining'. ❌ 降っても = 'even if it rains'. ❌ 降ると = 'whenever it rains'. 💡 Plain past + ので = because (cause).

Sentence structure · Question 17

昨日きのうの夜よる家いえに帰かえってから、鍵かぎを（　　）覚おぼえていません。

  1. どこに置おいたか
  2. どこに置おく
  3. どこに置おいて
  4. どこに置おいたら
Correct answer + explanation: どこに置いたか覚えていません = 'I don't remember where I put the key.' Embedded question: [question word] + plain past + か + 覚えていない. ❌ どこに置く = non-past, wrong tense. ❌ どこに置いて = te-form, incomplete. ❌ どこに置いたら = conditional. 💡 Embedded wh-question + か before verbs of remembering.

Sentence structure · Question 18

私わたしはピアノを（　　）時間じかんがありません。

  1. 引ひくのが
  2. 引ひく
  3. 最近さいきんす
  4. 好すきですが
Correct answer + explanation: Sentence assembly: ピアノをひく時間がありません = 'no time to play piano'. ★ = ひく (dictionary form modifying 時間). ❌ ひくのが = 'playing (it)' — nominalized, would need が before 時間. ❌ 最近す — incomplete. ❌ 好きですが = 'like, but…' — no connection. 💡 Dictionary form + noun = 'time to 〜'.

Sentence structure · Question 19

祖父そふが大切たいせつに（　　）時計とけいを、私わたしは今いまも使つかっています。

  1. 使つかっていた
  2. 使つかって
  3. 使つかう
  4. 使つかったら
Correct answer + explanation: 使っていた = 'used to use' (past progressive): 祖父が大切に使っていた時計 = 'the watch grandfather treasured and used.' 〜ていた modifies a noun for a past habitual state. ❌ 使って = te-form cannot end a noun-modifier. ❌ 使う = non-past, loses the 'used to' sense. ❌ 使ったら = conditional. 💡 Plain past 〜ていた + noun = a past state describing the noun.

「来週らいしゅう、野球やきゅうの試合しあいを見みに行いこうと思おもっているんですが、いっしょにどうですか。」

  1. ぜひ行いきたい

Correct answer + explanation: Sentence assembly: ぜひ行きたいです = 'I definitely want to go'. ❌ ことがない = 'there's no (experience of)' — incomplete alone. ❌ 見に行った = past — the event is next week. ❌ ので = because — no reason follows. 💡 ぜひ + たい = enthusiastic desire.

  3. 楽たのしかった

Correct answer + explanation: アルバイトする = はたらく (to work). Same meaning: はたらいています. ❌ まっています = waiting. ❌ 飲んでいます = drinking coffee. ❌ 話しています = talking with friends. 💡 アルバイト = part-time job → the action is working.

Vokabeln · Question 44

わたしは水泳すいえいがすきです。

  1. わたしは走はしるのがすきです。
  2. わたしは泳およぐのがすきです。
  3. わたしはごはんを食たべるのがすきです。
  4. わたしはほんを読よむのがすきです。
Correct answer + explanation: 水泳 (すいえい) = swimming = およぐこと. Same meaning: 泳ぐのが好き. ❌ 走る = run. ❌ 食べる = eat. ❌ 読む = read. 💡 水泳 literally 'water-swim' = the sport of swimming.

Vokabeln · Question 45

それを聞きいてびっくりしました。

  1. それを聞きいてわらいました。
  2. それを聞きいてこまりました。
  3. それを聞きいておこりました。
  4. それを聞きいて驚おどろきました。
Correct answer + explanation: びっくりしました = was surprised. Same meaning: 驚きました (おどろきました). ❌ わらいました = laughed. ❌ こまりました = was troubled. ❌ おこりました = got angry. 💡 びっくりする = 驚く — identical emotion.

Adjektive · Question 46

あのひとは美うつくしいですね。

  1. あのひとはきれいですね。
  2. あのひとは元気げんきですね。
  3. あのひとはおもしろいですね。
  4. あのひとはわかいですね。
Correct answer + explanation: うつくしい = beautiful. Same meaning: きれい. ❌ 元気 = healthy/energetic. ❌ おもしろい = interesting. ❌ わかい = young. 💡 うつくしい describes appearance — きれい is the everyday equivalent.

Verb conjugation · Question 47

さいきん毎朝まいあさジョギングを（　　）ようになりました。

  1. する
  2. して
  3. した
  4. できる
Correct answer + explanation: 〜ようになる = 'came to do (habitual change)': takes dictionary form → する. ❌ して = te-form. ❌ した = past. ❌ できる = 'can do' — changes the meaning to ability. 💡 ようになる = gradual change: する→するようになる.

Vokabeln · Question 48

日本語にほんごの先生せんせいになる（　　）、大学だいがくに入はいりました。

  1. からに
  2. ように
  3. ことに
  4. ためために
Correct answer + explanation: 〜ために = 'in order to': 先生になるために大学に入りました = 'entered university in order to become a teacher'. ❌ からに — wrong form. ❌ ように = 'so that' — used with potential/wishes, not deliberate goals. ❌ ことに — wrong pattern. 💡 Purpose: dictionary form + ために.

Partikel · Question 49

事故じこがあった（　　）、道みちがこんでいます。

  1. を
  2. そうに
  3. からに
  4. ためために
Correct answer + explanation: 〜ために = 'because of/due to': 事故があったために、道がこんでいます = 'because of the accident, the road is congested'. ❌ を — object marker. ❌ そうに — wrong form. ❌ からに — wrong form. 💡 ために works for both purpose and cause.

Partikel · Question 50

その仕事しごと、私わたし（　　）させてください。

  1. に
  2. を
  3. で
  4. が
Correct answer + explanation: Causative request: 私にさせてください = 'please let ME do it'. に marks the person being allowed. ❌ を — would mark the job as the object of させる, but 私 is a person. ❌ で = means. ❌ が = subject — would make 私 the doer grammatically, but causative-permissive uses に. 💡 Causative + ください: [person]に + させてもらう/させてください.
